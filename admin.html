🛠 Developer tools

Only for the developer.
Developer tools are —
Simulates people using the app at the same time, from this browser. Technicians sign in, download everything, sync every ~30 s, go through Jobs / Parts requests / History, and every period send a Field Service Report and an Equipment Service Report (with signatures) and a parts request. Supervisors go through every tab of this panel, open reports, invoices, customers, parts and equipment, and answer the parts requests. Test accounts TEST01… and TESTSUP1… are created automatically. No emails are sent.
The window shows that person doing everything step by step. To make a tutorial from it: Tutorials → Start recording and share that window.
All the simulated people use this computer's internet connection. The hosting may block a connection that sends too many requests (real tablets each have their own). If that happens the test says at what pace it happened; set a limit below it, or run part of the people from another network.
Deletes in one step on the server. Download a backup first. Supervisors are never deleted, and stock quantities are not changed.
Record a how-to while you use the app — it also works while a load test is running. It records the screen (and your voice if you want) and writes each step with a picture of the screen at that moment. Steps in the technician app are recorded too when it is open in another tab of this browser.
When the browser asks what to share: choose this tab for a tutorial of the panel, or Entire screen / Window if you will also use the technician app in another tab.
Open the technician app in a new tab
One Excel file with a sheet for each part of the app: customers, service reports, report parts, invoices, invoice lines, payments, parts requests, vendor orders, inventory, stock movements, jobs, employees and the activity log. Signature images are left out (the .sql backup keeps them).
